# Roma a cinque ordini · bozza

Bozza della mappa interattiva del progetto di dottorato di Lorenzo Sabene. Comprende la rete delle fonti, la linea del tempo e i luoghi del progetto sulla pianta di Roma di Giovanni Battista Falda (1676).

Il sito è un unico file `index.html`: la pianta e le anteprime dei facsimili sono incorporate nel file, quindi funziona anche senza connessione. Viene pubblicato con Cloudflare Pages a ogni push sul ramo `main`, senza alcuna compilazione.

Pianta: G. B. Falda, *Nuova pianta et alzata della città di Roma*, 1676, Rijksmuseum, Amsterdam (pubblico dominio). Le anteprime dei frontespizi provengono da Library of Congress e Gallica (BnF). I dati sono in corso di verifica sulle fonti.
